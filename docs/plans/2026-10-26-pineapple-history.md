# 菠萝碰撞与每局历史记录

目标：五套菠萝的叶冠都参与碰撞，连同叶冠小于西瓜；首页可以查看每次得分，刷新续局不会重复记录。

- [x] 为菠萝增加与叶冠轮廓匹配的复合碰撞体，缩小整体尺寸。同步处理旋转、生长、碰撞合成、警戒线、落点预测、风格切换及存档恢复。
- [x] 扩展本机存档，保存每局分数、难度、最高水果、投放数量、开始/结束时间及结束原因；结束与主动重开各记一次，续局和撤回不拆分对局，兼容旧存档。
- [x] 首页增加历史入口和手机友好的记录面板，包含当前未结束对局、空状态和分批查看更多。
- [ ] 添加真实 Matter 碰撞及历史持久化回归，检查手机尺寸界面和实际叶冠托举，构建后发布 GitHub Pages 并核对部署结果。

依赖：先完成碰撞体创建与尺寸辅助函数，再接入游戏和回归；历史数据先独立实现，再接入结算、重开和界面。保持新四套风格无表情、原版有表情。

验收重点：水果落在叶冠会产生接触；倾斜菠萝不穿墙/地板；生长后尺寸正确；叶冠接触触发同级合成；刷新、切换风格与撤回保持运动状态；零分的已玩对局记入历史，未投放的新局不记；历史损坏不影响健康存档；区分桌面浏览器验证与未执行的真实手机验证。
