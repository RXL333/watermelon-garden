# 水果风格接入

目标：手机上可选择原版、写实、卡通、毛绒、黏土五套水果。只有原版保留表情，每套有预览和简短介绍，选择会在本机保存。

1. [x] 将四套已选预览整理成有充分透明边距的正式图集。检查每个水果、叶冠、果梗均在独立裁切框内，记录材质与来源。
2. [x] 建立共享风格目录与裁切数据。Phaser 只在需要时加载所选素材，切换只更新渲染，保留当前刚体、得分、出果队列和撤回次数。存档兼容旧版与无效值。
3. [x] 在手机主界面增加风格入口；选择面板有五套预览和介绍。游戏画布、瞄准、下一个水果、进化条、弹窗、图鉴同步使用所选风格，刷新后恢复。
4. [ ] 扩充全部图集边界、偏好兼容与切换状态回归。浏览器检查 390×844、320×568，覆盖游戏中切换、图鉴、合成、续局及原版回切。完成构建、发布包和 GitHub Pages 部署，按实际执行范围记录验收。

主要文件：`src/fruit-art.ts`、`src/icons.ts`、`src/storage.ts`、`src/game.ts`、`src/main.ts`、`src/style.css`、`public/assets/`、`tests/atlas.test.ts`、风格回归测试、`ASSETS.md`、`README.md`、`TESTING.md`。

验收重点：无串图或缺叶；新风格没有五官；更换风格不重开、不改变物理尺寸；取消与加载失败保留原选择；按钮可触达；失败状态可重试；旧存档照常恢复；生产资源在 Pages 子路径可加载。
